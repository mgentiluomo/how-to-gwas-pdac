# Section 1B - Results

## What goes in this folder

- Small output files used by `01B_genotyping_qc.qmd`, such as PNG plots, tiny TSV summaries,
  or short text reports.
- Example outputs that help reviewers see what the tutorial should produce.

Do not place large genotype files, full PLINK output folders, or private project data here.
Learners should generate full runtime outputs in their own `results/qc/` folder.
