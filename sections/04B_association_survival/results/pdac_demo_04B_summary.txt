HOW TO READ THIS SCAN
  Section 03B gives the detectable effect sizes for 167 events. A null
  result at this event count is the expected outcome, not a failure of the
  analysis. But a null scan and an uncontrolled scan are different things:
  lambda and the suggestive count are interpretable only against the lambda
  this test gives when the null holds by construction, which
  04_permutation_null.R measures by permuting the outcome. Report the event
  count, the covariates, lambda, its permutation null and the minimum
  detectable hazard ratio together, so that a reader can tell an
  uninformative scan from a negative one.
