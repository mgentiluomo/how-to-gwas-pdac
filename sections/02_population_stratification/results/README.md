# Example results

Outputs of one locked-in run of the scripts in `../scripts/` on the demonstration
dataset. They are committed so that the website can display them without re-running
the pipeline at build time, and so that a reader can compare their own numbers.

Only small files live here: PNG figures, summary tables and eigenvalues. Genotype
files, full summary statistics and other large or regenerable outputs are excluded by
`.gitignore` and are reproduced by running the scripts.
