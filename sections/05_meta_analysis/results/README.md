# Example results

Outputs of one locked-in run of the scripts in `../scripts/` on the demonstration
dataset, committed so that the website can display them without re-running the
pipeline at build time.

Only small files live here. The harmonised and meta-analysed summary statistics
(`pdac_demo_05_harmonised.tsv.gz`, `pdac_demo_05_meta.tsv.gz`) are large and
regenerable, and are excluded by `.gitignore`.
